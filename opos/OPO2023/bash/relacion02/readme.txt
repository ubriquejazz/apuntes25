
RELACIÓN DE EJERCICIOS SISTEMA OPERATIVO LINUX 
PROGRAMACIÓN DE FICHEROS SCRIPTS EN SHELL BASH

Recomendaciones:
a) Introducir comentarios de cabecera que definan lo que hace el script y como se usa
b) Emplear comentarios de línea para las sentencias mas significativas
c) Siguiendo las normas de la programación estructurada, debería haber un único punto de salida y devolver 
   el valor 0 si todo ha ido bien y 1 si ha habido algún tipo de error durante la ejecución del script.
d) Cuidar el estilo de escritura, empleando la tabulación adecuada.
e) Optimizar el código para evitar la redundancia, siempre que sea posible
f) Enfoque más sencillo posible y en sucesivas revisiones mejorar el código del script.
