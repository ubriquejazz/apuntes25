## buscar.sh [SAI 2021]

Shell script de de Linux que simule el comando find. Podrá recibir de 1 a 3 argumentos:

- Un par --> el fichero a buscar en el directorio actual
- Dos par --> Directorio (absoluto) y fichero a buscar en el o fichero y opción "-s" para buscar ruta actual y subdirectorios
- Tres par--> Directorio (absoluto),fichero y opción "-s": buscará el fichero en la ruta y subdirectorios

## examen02.sh [SAI 2021]

## [PTFP 2004]

Realizar un programa que admita como argumento el nombre de un directorio.
Mostrará por pantalla una relación de ficheros y subdirectorios que estén contenidos en ese directorio. Se escribirá una entrada en cada línea. A cada fichero le precederá un carácter indicando el tipo de fichero correspondiente (se puede hacer uso de la función stat, una vez obtenida cada entrada). Se incluirán parámetros en la línea de órdenes:
    
    -f mostrará tanto ficheros como directorios. Si no aparece se mostrarán solo directorios.
    -o se mostrarán también los ficheros ocultos
    -l se mostrará información detallada (similar a ls -l)
    -r para cada directorio se volverá a analizar como si se tratara del original, 
       formándose una estructura de árbol (de forma recursiva)
