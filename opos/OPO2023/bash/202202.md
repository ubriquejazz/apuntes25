## Ejercicio propuesto con pings

Se trata de programar un script en Linux mediante la shell Bash, en el que acepte como argumento de entrada una dirección de red (nombre_script argumento1)

La llamada al script debe ser algo así: 

    ./escanear.sh 192.168.1.0

El script debe comprobar todas las direcciones de red comprendidas entre la 1 y la 254, es decir, desde la 192.168.1.1 hasta la 192.168.1.254 mediante el comando ping, por ejemplo.

Las direcciones IP que estén activas, pues el comando ping responderá positivamente, se mostrarán en pantalla un mensaje indicando que la dirección IP está activa, a la vez que se guardará en un archivo denominado Red-<argumento1>.txt (Ej. Red-192.168.1.0.txt en el caso de ser esta la red introducida como parámetro). 

Tanto en pantalla como en el fichero resultado tendremos una lista de direcciones IP's activas detectadas en la red indicada como argumento.

Se trata de un ejercicio práctico con orientación didáctica, dirigido a comprobar el funcionamiento de la variable especial $? y de las instrucciones de manipulación de caracteres, entre otras.
Es cierto que existen ya comandos en Linux capaces de realizar auditoría de red, como es el caso de **nmap**, que en esta práctica evitaremos emplear.
