# Generación de Código e Ingeniería Inversa

**Duración:** 6h, semanas hasta el 7/11

## Objetivos:

  - Generar código fuente a partir de diagramas de clases.
  - Aplicar el proceso de ingeniería inversa para crear diagramas de clases desde código existente.
  - Utilizar herramientas de software para la generación de código e ingeniería inversa.
  - Comprender la relación entre el codigo y el modelo.

## Contenidos:

  - Generación automática de código a partir de diagramas de clases (pseudolenguaje)
  - Ingeniería inversa: análisis de código fuente para la creación de diagramas de clases.

## Criterios de Evaluación:

  - e) Se ha generado código a partir de un diagrama de clases.
  - f) Se ha generado un diagrama de clases mediante ingeniería inversa.

## Actividades:

Exposición y Act. 1: **Generación de código a partir de diagramas de clases** (2h)

* Pasar a código Python los diagramas diseñados en la Act. 2. de UD102 

Exposición y Act. 2: **Ingeniería inversa** (1h)

* Análisis de código y creación de diagramas.

**Evaluación**: Proyecto integrador (3h).
