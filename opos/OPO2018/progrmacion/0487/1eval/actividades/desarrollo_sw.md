# UD102: Desarrollo de Software y Metodologías Ágiles

**Duración:** 6h, semanas hasta el 14/12 aprox (FFEOE)

## Objetivos

* Identificar las fases del ciclo de vida de desarrollo de una aplicación informática.
* Identificar las características y escenarios de uso de las metodologías ágiles de desarrollo de software.

## Contenidos

* **Fases del desarrollo de una aplicación:**
    * Análisis, Diseño, Codificación
    * Pruebas, Explotación, Mantenimiento
* **Metodologías ágiles:**
    * Características
    * Escenarios de uso
    * Técnicas Scrum y Kanban

## Criterios de Evaluación

* b) Se han identificado las fases de desarrollo de una aplicación informática ciclo de vida.
* g) Se han identificado las características y escenarios de uso de las metodologías ágiles de desarrollo de software.

## Actividades

Exposición y Act. 1: **Ciclo de Vida del Desarrollo de Software.** 1h

- Fases (análisis, diseño, codificación, pruebas, explotación, mantenimiento).

* Estudio de casos prácticos para ilustrar cada fase.

Exposición y Actividad 2: **Metodologías Ágiles**. 2h

* Introducción a los principios y valores de las metodologías ágiles.
* Análisis de las características clave de Agile (iteración, colaboración, flexibilidad).
* Exploración de escenarios de uso comunes para metodologías ágiles.

Exposición y Actividad 3: **Técnicas Scrum y Kanban**. 2h

- Estudio comparativo: simulación de proyectos utilizando estas técnicas.

**Evaluación** mediante examen (1h)

* Debate sobre las diferencias entre el ciclo de vida clasico, y las metodologias agiles.
