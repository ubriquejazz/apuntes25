# Desarrollo en Java con VSCode e IDEA IntelliJ

**Duración:** 9h, semanas del mes de Febrero (hasta el 21/02)

## Objetivos

- Configurar y personalizar entornos para el desarrollo de aplicaciones Java.
- Comprender y aplicar el sistema de construcción **Gradle** para la gestión de proyectos Java.
- Automatizar tareas de desarrollo utilizando Gradle.
- Comparar y contrastar diferentes entornos de desarrollo para Java: **VSCode** e **IntelliJ** IDEA

## Criterios de Evaluación:

- a) Se han instalado entornos de desarrollo, propietarios y libres.
- b) Se han añadido y eliminado módulos en el entorno de desarrollo.
- c) Se ha personalizado y automatizado el entorno de desarrollo.
- d) Se ha configurado el sistema de actualización del entorno de desarrollo.
- e) Se han generado ejecutables a partir de código fuente de diferentes lenguajes en un mismo entorno de desarrollo.
- **f) Se han generado ejecutables a partir de un mismo código fuente con varios entornos de desarrollo.**

- **g) Se han identificado las características comunes y específicas de diversos entornos de desarrollo.**

## Contenidos

1. **Preparación del Entorno de Desarrollo Java en VSCode (Criterio a y d)**
    - Instalación de VSCode y el "Extension Pack for Java".
    - Instalación del JDK (Java Development Kit).
    - Verificación de la correcta instalación y configuración de Java y VSCode..
2. **Personalización y Gestión de Extensiones en VSCode (Criterio b)**
    - Exploración e instalación de extensiones relevantes para el desarrollo Java (ej: linters, formatters).
    - Configuración de las preferencias de VSCode para Java (ej: temas, fuentes, atajos de teclado específicos).
    - Deshabilitación y eliminación de extensiones.
3. **Automatización de Builds con Gradle (Criterio c)**
    - Introducción a Gradle: conceptos clave (proyectos, tareas, plugins, dependencias).
    - Creación y estructura de un archivo `build.gradle` básico.
    - Configuración de tareas comunes (compilación, ejecución, empaquetado).
    - Gestión de dependencias externas utilizando Gradle.
    - Ejecución de tareas de Gradle desde la terminal integrada de VSCode y la vista de Gradle.
4. **Compilación y Ejecución en Múltiples Entornos (Criterio f y g)**
    - Generación de un archivo JAR ejecutable utilizando Gradle.
    - Instalación y configuración de IntelliJ IDEA 
    - Importación y ejecución del mismo proyecto Java en el nuevo IDE.
    - Comparación de las interfaces, funcionalidades y flujos de trabajo para el desarrollo Java.
    - Identificación de características comunes (editor de código, compilación, depuración) y específicas (integración con build tools, refactorización avanzada, etc.) de los diferentes IDEs.
