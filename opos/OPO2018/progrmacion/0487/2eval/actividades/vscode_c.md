# Desarrollo en C/C++ con VSCode

**Duración:** 9h, semanas de mes de Enero (hasta el 31/01)

## Objetivos

- Comprender el flujo de trabajo completo del desarrollo en C/C++, desde la instalación del entorno hasta la generación de ejecutables.
- Dominar la personalización y automatización de VSCode para optimizar el proceso de desarrollo.
- Familiarizarse con el uso de Makefiles para gestionar proyectos complejos.
- Explorar la compilación de código fuente en diferentes entornos y lenguajes.

## Criterios de Evaluación:

- **a) Se han instalado entornos de desarrollo, propietarios y libres.**
- **b) Se han añadido y eliminado módulos en el entorno de desarrollo.**
- **c) Se ha personalizado y automatizado el entorno de desarrollo.**
- **d) Se ha configurado el sistema de actualización del entorno de desarrollo.**
- **e) Se han generado ejecutables a partir de código fuente de diferentes lenguajes en un mismo entorno de desarrollo.**
- f) Se han generado ejecutables a partir de un mismo código fuente con varios entornos de desarrollo.
- g) Se han identificado las características comunes y específicas de diversos entornos de desarrollo.

## Contenidos

1. **Preparando el Entorno de Desarrollo (Criterios a y d)**
        Instalación de VSCode y extensiones esenciales para C/C++.
        Configuración de GCC (GNU Compiler Collection) en el sistema operativo.
        Exploración de la terminal integrada.
    
1. **Personalización y Extensión de VSCode (Criterio b)**
        Instalación y gestión de extensiones para VSCode.
        Personalización de la interfaz y configuraciones del editor.
        Uso de snippets y atajos de teclado para aumentar la productividad.

1. **Automatización con Makefiles (Criterio c)**
        Introducción a los Makefiles: sintaxis y estructura.
        Creación de reglas de compilación para proyectos simples y complejos.
        Gestión de dependencias entre archivos fuente.
        Automatización de tareas de compilación y limpieza.

1. **Compilación Multilenguaje y Multiplataforma (Criterio e)**
        Compilación de código C y C++ en VSCode.
        Configuración de VSCode para diferentes compiladores.
        Generación de ejecutables para diferentes sistemas operativos.

Act. consolidación: Instalación y verificación del entorno.

Exposición: **Personalización y primeros pasos en C.** 3h
